Put disk images for the Virtual Machine tab in this folder. They show up in the VM tab automatically.

  windows95.img   a Windows 95 hard disk image (the "Windows 95" preset picks it up by name and starts it automatically)
  windows98.img   the same for Windows 98
  *.iso           CD-ROM images
  *.img (1.44 MB) floppy images; anything bigger is treated as a hard disk

Rel Zone does not include Windows or any other operating system. Use images you have the right to use.
You can also skip this folder and pick a file from your computer in the VM tab (it is loaded in your browser only).
